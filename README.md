# 🚀 KT PostMaker - Instagram Carousel Generator

KT PostMaker adalah aplikasi berbasis web *(Client-side)* yang dirancang khusus untuk pengurus Karang Taruna guna menciptakan konten Instagram Carousel dengan estetika modern, youth movement, dan profesional tanpa perlu keahlian desain grafis yang rumit. Karena kadang organisasi pemuda butuh branding juga, bukan cuma rapat 4 jam untuk menentukan warna spanduk lalu pulang tanpa keputusan.

---

## ✨ Fitur Utama

### 🎨 Desain Modern & Clean
Tema visual yang disesuaikan dengan semangat pemuda *(Orange & Slate)* dengan sentuhan:
- Mesh Gradient
- Glassmorphism
- Soft Glow
- Modern Carousel Layout

---

### 📝 Real-time Editor
Ubah teks, judul, dan deskripsi slide secara langsung dan lihat hasilnya secara realtime di panel preview.

---

### 🖼️ Export PNG
Mengunduh slide satu per satu menjadi file gambar berkualitas tinggi *(1080x1350 px)* menggunakan **html2canvas**.

---

### 💾 Auto-Save
Menggunakan `localStorage` browser untuk menyimpan progres kerja Anda secara otomatis.

Karena hidup sudah cukup keras tanpa kehilangan draft carousel setelah refresh browser.

---

### 📱 Responsive Preview
Tampilan artboard yang adaptif untuk memastikan keterbacaan di berbagai ukuran layar.

---

### 🎭 Animasi AOS
Transisi halus saat memuat aplikasi untuk pengalaman pengguna yang lebih premium.

---

# 🛠️ Teknologi yang Digunakan

Aplikasi ini dibangun menggunakan teknologi modern vanilla web stack tanpa backend:

- HTML5 & CSS3
- Tailwind CSS
- AOS.js
- SweetAlert2
- html2canvas
- Vanilla JavaScript

# 🚀 Cara Penggunaan

Karena aplikasi ini tidak memiliki backend, Anda tidak perlu melakukan instalasi yang rumit ataupun ritual DevOps tengah malam.

## 1. Clone Repositori

```bash
git clone https://github.com/itsmebroarif/katarpostmaker.git
```

---

## 2. Buka File

Cukup buka file `index.html` di browser favorit Anda:
- Google Chrome
- Microsoft Edge
- Mozilla Firefox

---

## 3. Mulai Berkreasi

- Edit teks di sidebar kiri
- Tambahkan slide baru
- Export desain menjadi PNG
- Upload ke Instagram
- Rasakan dopamine engagement sosial media modern
